Projects

ProfAI

ProfAI is a generative AI web application that allows faculty members on the GVSU campus to create realistic videos of any content they would like to teach. The project requests users to head to HeyGen to create an account, a realistic avatar, and an API key. Then, a user may connect their API key through our web application to gain access to their avatar. Moving forward, users enter in a content prompt (examples include "World War 2", "Intro Calculus", or "Ethical Law"), and a script will be generated. Once the script is approved, a video using their avatar along with a slideshow in the back, teaching using the script, will be available for download for instructors to use as content videos.

This web application uses a React frontend along with a Django backend. The application requires several APIs to communicate, including ChatGPT's assistant API, HeyGen API, GoogleSlidesAPI, and ElevenLabs API. The application is currently under construction, and is planned to be managed by GVSU IT Innovation and Research.
